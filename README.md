# Bavly Hany Portfolio (React + Vite + Supabase)
1. Supabase: New project > SQL Editor > run supabase.sql
2. Authentication > Users > Add user (email + password) — this is your admin login
3. Authentication > Sign In / Providers > disable "Allow new users to sign up"
4. Copy .env.example to .env and fill URL + anon key (Project Settings > API)
5. npm install && npm run dev  — Admin: /#/admin

6. Run supabase-storage.sql (images) and supabase-v2.sql (messages table) in SQL Editor
